Link converter

Paste an X (Twitter) post or any web/news article URL. X links become xcancel.com; everything else gets a Wayback Machine snapshot link.

Open
X hosts: x.com, twitter.com, mobile.twitter.com, m.x.com — rewritten to xcancel.com with tracking params (s, t, ref_src, ref_url, cxt) stripped.
Other URLs: prefixed with https://web.archive.org/web/; Wayback redirects to the latest snapshot, or offers Save Page Now if none exists.
